Snackbar

The inherited Ecology snackbar, wearing the Biochar Atlas skin. A toast stack driven imperatively — call show(), or the variant shorthands, on a single container placed once on the page; tones resolve from the spoke's semantic tokens.

Inherited wc import '@esa/ecology/esa-snackbar';

Preview

Place one esa-snackbar-container on the page, then drive it imperatively — call show(), or a variant shorthand, on the element itself.

Variants

The triggers are deliberately neutral. Colouring a button by the tone it will raise makes the button claim an outcome before the action has run — a red "score this field" reads as destructive. The tone belongs on the toast, which is the thing reporting what happened.

With an action

An action label renders a button on the toast. Pressing it fires action on the item — the container re-dispatches this as snackbar-action — and dismisses the toast.

Duration and dedupe

Set duration: 0 to keep a toast on screen until it's dismissed manually. Set uniqueKey to dedupe — click "Note missing coverage" more than once and only one toast stays on screen, because the second call returns the existing toast's id instead of stacking a duplicate.

API

esa-snackbar-container

Grab the container by id and call its methods directly.

PropTypeDefaultDescription
show(config) method — Displays a toast built from an EsaSnackbarConfig. Returns its id.
success(message, config?) method — Shorthand for show() with variant: 'success'.
info(message, config?) method — Shorthand for show() with variant: 'info'.
warning(message, config?) method — Shorthand for show() with variant: 'warning'.
danger(message, config?) method — Shorthand for show() with variant: 'danger'.
dismiss(id) method — Removes the toast with that id and clears its auto-dismiss timer.
clearAll() method — Removes every active toast.

Events

EventTypeDefaultDescription
snackbar-action CustomEvent<{ id: string }> — Bubbles from the container when a toast's action button is pressed.

Config object (show)

PropTypeDefaultDescription
message string — Toast body text.
variant 'info' | 'success' | 'warning' | 'danger' 'info' Tone — background and leading icon.
duration number 5000 Auto-dismiss delay in ms. 0 keeps the toast on screen until dismissed.
action string — Optional action button label.
dismissable boolean true Shows the close button.
uniqueKey string — Dedupe key — a second show() carrying a uniqueKey already on screen returns the existing toast's id instead of stacking a duplicate.

esa-snackbar-item

Usually rendered by the container for each active toast, but it also works standalone.

PropTypeDefaultDescription
message string '' Toast body text.
variant 'info' | 'success' | 'warning' | 'danger' 'info' Background and leading icon. Reflected attribute.
action string '' Optional action button label. Omit to hide the button.
dismissable boolean true Shows the close (×) button.

Events

EventTypeDefaultDescription
action CustomEvent — Fired when the action button is pressed. The item also dismisses itself, so a dismiss event follows immediately.
dismiss CustomEvent — Fired when the close button is pressed, or automatically right after action.

Biochar Atlas / Core / Button

Button

The inherited Ecology button. Its primary is ABI Green, because the theme re-points --color-primary. Purple and Gold arrive through bca-button, which sets the same private knobs to brand values — the identity half of the set, beside the conventional one.

Inherited .astro import EsaButton from '@esa/ecology/esa-button.astro';

Brand tones

Green, Purple and Gold are the ABI palette's action colors: emphasis and calls to action. Green is primary — there is no second green. Purple's fill is step 11 rather than the issued #45173d, which is a text color and reads as a black button at fill scale; the issued hex returns as the hover. Gold takes a dark label at 6.54:1 — white on Gold is 1.60:1.

Brand tones, outlined

Gold is the one tone whose border cannot be its fill: the issued Gold is 1.53:1 against the panel, so an outlined Gold button draws its border and its label from --bca-tone-gold-strong instead.

Emphasis

What a button carries when it is not a brand call to action. Secondary is the Sage neutral; ghost is transparent until hovered.

Destructive

Conventional red, deliberately not brand. A destructive action should read as destructive to someone who has never seen this palette — which is also why the status families stay off the brand.

Status colors

Success, warning and info exist on the lego and resolve to this spoke's status families. They belong on badges, alert boxes and score bars; a button is an action, and colouring one by status describes the outcome before it has happened. Shown here so the set is documented, not to recommend it.

Sizes

The action slot of bca-page-header sets its own size, so a button slotted there needs no size — it lands at the dense scale, 13px label in a 32px box with a 4px corner, matching the control strip below it. The slot re-points the md family only, so an explicit size still wins where a surface genuinely needs one.

With icons

Pass a Lucide icon name via icon; add iconOnly to drop the label.

API

PropTypeDefaultDescription
color 'primary' | 'secondary' | 'danger' | 'success' | 'warning' | 'info' | 'ai' | 'ghost' 'primary' Semantic color role. Primary is ABI Green — the theme re-points --color-primary.
appearance 'fill' | 'outline' | 'dashed' | 'soft' 'fill' Solid, outlined, dashed-outline, or a neutral surface that fills with the accent on hover.
size 'xs' | 'sm' | 'md' | 'lg' 'md' Control size (shared form scale).
icon string — Lucide icon name, shown left of the label.
iconOnly boolean false Icon-only mode (no text).
active boolean false Pressed/active state.
disabled boolean false Non-interactive state.
loading boolean false Shows a spinner and blocks input.
href string — Renders an anchor styled identically — a link that looks like a button.
type 'button' | 'submit' | 'reset' 'button' Native button type.

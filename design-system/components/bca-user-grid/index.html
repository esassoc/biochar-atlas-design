Data grid

The house grid every admin collection reuses — a control strip, an AG Grid on the Atlas theme, and a record-count strip welded underneath. A port of Beacon's grid page, palette-swapped, with Beacon's density held.

Spoke .astro import BcaUserGrid from '../../components/bca/bca-user-grid.astro';

Anatomy

Three bands that read as one frame rather than three stacked elements. The control strip is a bordered container above; the grid squares its bottom corners; the count strip repeats the border with its top edge removed and rounds the bottom.

This is the shipped component, not a copy of it — search, sort, filter, CSV export and row-to-panel all work here exactly as they do on Admin › Users. Click any row.

0 users

Density

Cells and header run at 13px in 44px rows, and the control strip and count strip come down with them. That is below the 16px minimum this design system holds everywhere else, and it is deliberate: a dense data grid is the surface where the number of rows a person can compare at once beats the comfort of any single row. The exception covers the dense data surfaces — this pattern and the record panel that reads out of a row — and stops there. Page content is still at the floor.

Columns fill the grid

The house default is flex: 1 with a minWidth, and a page sets a flex weight per column rather than a width. Six columns therefore divide the whole grid between them and the last one ends at the right edge, instead of stopping two-thirds across and leaving a dead band beside it.

flex rather than sizeColumnsToFit(), for two reasons. It is declarative — AG Grid re-solves it on container resize with no gridSizeChanged handler to write, so there is nothing to thrash. And it survives a manual drag: sizeColumnsToFit() bound to a resize event snaps every column back and silently undoes the resize the user just made.

minWidth does the real work. Below it a column stops shrinking and the grid scrolls, so a narrow window truncates nothing that matters — put the floors on the columns whose values truncate worst, which here are Name and Email.

Status cells

Colour marks the exception, not the value. Of ten accounts eight are active, so tinting that makes a green column carrying no decision. Invited is the one value asking someone to act, so it is the only chip with a fill and the eye lands on it directly. Deactivated recedes — an inert account is an end state, not a failure.

Nothing here is red. No account status is an error, and spending the danger colour on one would leave nothing to spell an actual failure with. The tinted chip mixes its tone at 16% for the fill and 70% against the body ink for the label: 5.63:1 on the panel, 5.23:1 on the zebra row and 4.91:1 on a hovered row — the hovered row being the binding case rather than the resting one.

API

Theme parameters

atlasTheme in src/lib/bca-grid.ts. AG Grid resolves theme params at config time and cannot read CSS custom properties, so every value is a literal annotated with the token it mirrors — keep the two in sync by value.

PropTypeDefaultDescription
headerHeight / rowHeight number 48 / 44 Beacon’s numbers. The row height carries the density; the header sits one step taller so the slab has presence.
headerFontSize / dataFontSize string '13px' Below the app’s 16px minimum by explicit decision. The carve-out covers the grid module only.
headerBackgroundColor / headerTextColor string '#364500' / '#ffffff' Brand Green with white labels, 10.46:1.
backgroundColor string '#fafaf7' The panel. Quartz defaults this to white, which puts rows on a surface the app has nowhere else.
oddRowBackgroundColor string '#f2f1e9' Sage 3 — the shell’s own hue, ΔE 0.0284 from the panel. A neutral zebra measures 0.0139 and disappears.
rowHoverColor string '#e6eae0' Green 3, ΔE 0.0540 from the panel.
accentColor string '#364500' Sort arrows, active filters, checked checkboxes.
wrapperBorderRadius string '4px 4px 0 0' Bottom corners squared so the count strip welds under the grid. atlasCardTheme rounds all four, for a grid that ends at its last row.

Cell renderers

PropTypeDefaultDescription
makeStatusChipRenderer(tones) function — Returns a cell renderer drawing a dot, a label and an optional tint. Each tone is { chip: hex, quiet?: boolean }; the consuming component supplies the matching :global CSS, because AG Grid builds cells outside Astro’s style scope.
makeLinkRenderer({ href }) function — The primary cell as a real anchor. href builds the destination from the row, so copy-link and middle-click still work even though a left click is intercepted to open the panel.

Grid options that matter

PropTypeDefaultDescription
atlasDefaultColDef ColDef — Pass as defaultColDef. Carries sortable / resizable / filter / tooltip plus flex: 1 and minWidth: 120, so columns fill the grid by default and a page only sets the weights it wants to differ.
getRowId (p) => string — Set to the record id. Without it a saved edit cannot find its node and has to rebuild rowData, losing sort, filter and scroll position.
onRowClicked (e) => void — Opens the record. Guarded against the anchor in the name cell so the two gestures do not fire together; guard against .ag-checkbox too on any grid with selection.

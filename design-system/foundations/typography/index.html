Typography

The ABI brand faces: Inter for the interface, Crimson Pro Light for headlines. JetBrains Mono carries data values. Sentence case throughout — the brand does not set Title Case.

Weights

The brand names three identity weights — Light, Regular, Bold. Label hierarchy at this data density needs a mid weight too, so 500 and 600 are loaded and mapped as an extension, the same way the color ramps extend the issued palette. Components read --font-weight-*; never hard-code a DM Sans number (350 / 450 / 550 / 650) in this spoke.
